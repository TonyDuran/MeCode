# MeCode 2.0

An offline-first desktop coding-practice tool, intended for Linux and Apple Silicon macOS. The goal is a focused place to work through algorithm problems, write solutions, run tests, and track progress locally.

## The vision

- A curated problem catalog organized around common algorithm and data-structure patterns.
- An integrated editor with support for multiple programming languages.
- Local solution execution and judging, with clear results and an explicitly tested isolation boundary.
- Saved drafts, results, and progress without depending on a hosted practice platform.
- A polished desktop experience with honest feedback when a capability is unavailable.

These are product goals, not claims about features currently implemented.

## Why 2.0?

**Because 1.0 failed to deliver the finished app.** 😂

The first attempt produced useful prototypes, tests, and lessons, but did not reach an accepted, integrated product. Green checks and a ZIP file were not the finish line.

This is a fresh start, not an upgrade to a shipped 1.0 release. Earlier work remains in Git history for reference; it is not the implementation baseline for 2.0.

## Current status

**Reset and awaiting the new project brief.** This README is an overview, not an implementation kickoff. Scope, architecture, milestones, and acceptance criteria for the second attempt are still to be agreed.

There is no runnable 2.0 application, installation package, or release yet. Do not use the earlier prototypes as a secure runner for untrusted code: their isolation and native lifecycle acceptance gates were not fully satisfied.
